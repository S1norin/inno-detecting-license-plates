\section{Milestone status}

Recognizer trained specifically on license plates. It works and it is much
better than the EasyOCR baseline from week 1.

In week 1 the recognizer was weak. The new recognizer reads 75\% of
characters correctly on clean plate crops, compared to 35\% for EasyOCR. On
the full pipeline (detector + recognizer) it goes from 32\% to 66\%. It also
reads whole plates correctly: 269 out of 800, where EasyOCR managed 0.

\section{Second approach}

\subsection{What changed}

In week 1 we found that EasyOCR does not work well on plate crops. Its
exact-plate score was 0 on the test set. So we trained our own recognizer
from scratch on CCPD plate crops. A model trained on plates should know what
plates look like, which a general OCR model does not.

\subsection{Model}

The model is a CRNN: convolutional layers that read the image, two
bidirectional LSTM layers that track the sequence of characters, and a CTC
output that turns the sequence into text.

\begin{itemize}
\item Input: one grayscale crop, 48~px tall, up to 256~px wide, aspect
  ratio kept.
\item Character set: the 58 characters that appear in the training plates.
\item Size: about 3 million parameters.
\item Code: \texttt{models/crnn/}.
\end{itemize}

We kept the run fully reproducible: same seed, deterministic mode, one
thread. Two independent runs produced byte-identical checkpoints.

\subsection{Evaluation protocol}

We use the same evaluation harness as week 1, so the numbers are directly
comparable. Two protocols:

\begin{itemize}
\item \textbf{OCR-only} --- the recognizer reads clean plate crops. This
  measures the recognizer alone.
\item \textbf{End-to-end} --- the YOLO detector finds the plate first, then
  the recognizer reads it. This is the full system.
\end{itemize}

For each protocol we pick the preprocessing mode and confidence threshold
on the validation set only. The test set is then run exactly once with that
fixed policy. The test set was never used to choose anything.

\item Large plates are read much worse than small ones (57\% vs 86\%).
\item The 10--19 degree tilt bin is the weakest (51\%, only 63 samples).
\end{itemize}

\subsubsection{Confidence threshold (E6)}

We swept the confidence threshold from 0.50 to 0.99 on validation and
picked the threshold that keeps the most plates without losing accuracy.
Both protocols selected threshold 0.50 with the ``none'' preprocessing
mode. The test set was then run once with that fixed policy.

\section{Observations}

\begin{itemize}
\item The plate-specific model is the fix we needed. It doubled character
  accuracy and went from 0 to 269 exact plates on clean crops.
\item The full pipeline is still a bit below the clean-crop number (65.6\%
  vs 75.4\%). Part of that gap is the detector missing 17 plates, and part
  is that a detector box is a rougher crop than the ground-truth box.
\item Large plates suffer because we squash them into a 48~px tall input.
  The characters become tiny. A taller input for large plates is the
  obvious next step.
\item The 10--19 degree bin is the weakest tilt group. It is also the
  smallest, so we should be cautious about over-interpreting it.
\item Canny preprocessing destroys most of the signal for a trained model.
  The selection correctly avoided it.
\end{itemize}

\section{Remaining work}

\begin{itemize}
\item Fine-tune YOLO11 on our training split and compare it to the
  pretrained detector. Then re-run end-to-end recognition with the better
  detector.
\item Try a taller input for large plates to improve their accuracy.
\item Final submission (10 November): failure-case analysis, runtime and
  memory numbers, reproducibility check on a clean clone, two-page summary,
  and demo.
\end{itemize}

\section*{Limitations}

\begin{itemize}
\item Our split is custom, so the numbers are not comparable to official
  CCPD benchmark results.
\item Tilt bins come from a filename proxy and have very unequal sizes
  (570 vs 167 vs 63).
\item Timing measurements so far cover 100 sampled images, not the full
  splits.
\end{itemize}
